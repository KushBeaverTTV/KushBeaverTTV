## Cornerstone — an Omarchy status-bar suite

A family of plugins that turn the Omarchy (Hyprland) bar into a control surface:

- **cornerstone-island** — a Dynamic Island for the desktop: music, notifications, timers, calendar, and live activities in a notch at the top of the screen
- **cornerstone-dictation** — local Whisper speech-to-text in the bar, with push-to-talk and live status
- **cornerstone-keyboard** — an AI-agent keyboard (forked from FUTO Keyboard): in-keyboard agent conversations, voice dictation, device control
- **cornerstone-phones** — battery levels and noise-cancellation control for Bluetooth headphones, in the bar
- **cornerstone-audio** — volume slider, output picker, and a per-app mixer with a device picker for each app
- **cornerstone-desktop** — the tools behind the plugins: dictation, window helpers, task manager, quota reader
